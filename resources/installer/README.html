g-calendar.app→Программы
  1. Закройте уже запущенный g-calendar.
  2. Перетащите приложение на ярлык Applications в этом образе.
  3. Откройте g-calendar из «Программ», затем извлеките образ.
  4. В настройках приложения отдельно настройте Google Workspace CLI (gws) и вход Google.

Образ содержит только приложение. Настройки, кэш и локальные напоминания хранятся отдельно. Установщик не входит в Google и не устанавливает gws.

Локальный пакет с суффиксом -local подписан ad-hoc и предназначен для локальной проверки. Он не является нотарифицированным публичным выпуском. Не отключайте Gatekeeper и не удаляйте quarantine.
