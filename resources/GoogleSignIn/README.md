# Google sign-in asset

`g-logo.png` is the official Google “G” sign-in mark downloaded from Google's
branding assets. The app displays it inside the white, outlined sign-in button
and does not recolor or modify the mark.

- Branding guidance: https://developers.google.com/identity/branding-guidelines
- Original asset bundle: https://developers.google.com/identity/images/g-logo.png
