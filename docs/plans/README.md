# Дизайны и локальные планы

В Git сохраняются согласованные продуктовые дизайны с именем `YYYY-MM-DD-<тема>-design.md` и этот README.

Рабочие планы реализации, ExecPlan, промежуточные чеклисты и заметки агента храните здесь локально. Остальные Markdown-файлы этой папки, а также папки `/plans/` и `/.codex/plans/` исключены через `.gitignore`. Не добавляйте их принудительно. Ранее отслеживаемые рабочие планы убраны из индекса Git; локальные файлы сохранены, прошлые версии доступны в истории коммитов.

Полезные для проекта требования, решения и результаты сохраняйте в [OpenSpec](../../openspec/changes/g-calendar-mvp/), [журнале проверок](../verification.md), [статусе](../STATUS.md) и тематических документах. Датированные исследования в `docs/` остаются в Git.
