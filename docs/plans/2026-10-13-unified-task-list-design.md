# Единая лента задач

Согласовано пользователем 13 октября 2026 года. В режиме «Список» выбор «Все доски» показывает единую ленту, сортируемую по общему правилу. Сортировка по дате объединяет задачи всех досок в общие разделы дат. Название доски показывается меткой в строке. Лента занимает доступную ширину и начинается на одной линии с фильтрами. Режим «Колонки» сохраняет доски; на узком окне используется единая лента. Отдельно выбранная доска сохраняет свой порядок и представление.

Сохраняем отдельное общее правило сортировки в локальных предпочтениях. Старое одинаковое правило досок используется при миграции, смешанные правила дают сортировку по дате. Google операции не меняются. Клавиатурный порядок соответствует видимой ленте, перетаскивание допустимо только внутри одной доски в ручной сортировке. Проверки используют синтетические задачи, в том числе одинаковые ID в разных досках.
