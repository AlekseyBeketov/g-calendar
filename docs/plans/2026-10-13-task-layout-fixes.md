# Calendar order and task layout fixes

## Purpose / Big Picture

По прямому запросу Лехи переключатель календаря должен показывать День / Неделя / Месяц. В задачах первая доска должна целиком оставаться достижимой слева. UI-проверка выполняется синтетическими offscreen окнами; управление пользовательским приложением не запрошено.

## Surprises & Discoveries

TaskWorkspaceView использует GeometryReader, горизонтальный ScrollView и HStack фиксированных колонок. Причина обрезания устанавливается синтетическим воспроизведением с измерением фактических AppKit-рамок. Исходные изменения пользователя в AppMain.swift и тестах не относятся к этой задаче и не коммитятся.
