# Принятые решения и внешняя приёмка

Обновлено: **2026-10-07**.

## Утверждено

SwiftUI/AppKit, [Pixel Paper с task metadata Color Atlas](../design/DESIGN.md) и светлая тема как основной личный сценарий. System остаётся значением по умолчанию; Dark поддерживается. Week сохраняется в узком окне с горизонтальной навигацией; список задач — основной режим, колонки — отдельный. Upcoming содержит только будущие даты; задачи без срока показаны отдельно.

Владелец разрешил тестирование, Computer Use, сборки и создание/изменение/завершение/возврат/удаление собственных синтетических объектов с exact-ID ledger. Scope записан в [HUMAN_APPROVALS](HUMAN_APPROVALS.md). Текущие доступы Computer Use работают; повторное разрешение не требуется. План и доказательства — [ExecPlan](plans/2026-10-05-final-product-completion.md), [verification](verification.md), [OpenSpec](../openspec/changes/g-calendar-mvp/tasks.md).

## Внешние решения

- **Лицензия и публичный выпуск.** В репозитории пока нет `LICENSE`. Реализованные installer/release scripts не публикуют приложение.
- **Developer ID и notarization.** Нужны существующая signing identity, ожидаемый Team ID и Keychain profile владельца. Credentials не сохраняются в репозитории. Локальный ad-hoc пакет не подтверждает издателя или Gatekeeper-приёмку скачанного релиза.
- **Чистый Mac.** Проверить скачанные подписанные assets, первый запуск с сохранённым quarantine и обновление с сохранностью данных перед публикацией.
- **VoiceOver.** AX labels и клавиатурные сценарии проверены; полный ручной голосовой проход ещё не выполнен.
- **Видимый notification banner.** Доставка собственного тестового уведомления в Notification Center подтверждена; видимый баннер требует человеческого наблюдения.
