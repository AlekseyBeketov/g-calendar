# Принятые решения и открытая приёмка

Обновлено: 2026-10-05.

Утверждены SwiftUI/AppKit, Pixel Paper, task rows Color Atlas и светлая тема как основной личный сценарий при System по умолчанию и поддержке Dark. Week сохраняется в узком окне с горизонтальной навигацией; список задач — default, колонки — явный режим; Upcoming содержит только будущие даты; задачи без срока показаны отдельно. Контракт — [design/DESIGN.md](../design/DESIGN.md).

Разрешены fixture/computer-use тестирование, синтетические снимки и создание/изменение/завершение/возврат/удаление собственных тестовых объектов с exact-ID ledger. Scope — [HUMAN_APPROVALS.md](HUMAN_APPROVALS.md), повторно подтверждён 2026-10-05. OS prompts подтверждает человек.

Работа и evidence: [план](plans/2026-10-05-final-product-completion.md), [verification](verification.md), [OpenSpec](../openspec/changes/g-calendar-mvp/tasks.md). Производительность GUI измеряется до выбора бюджетов; микроbenchmark модели не заменяет эту проверку. Полный ручной VoiceOver проход не проведён.

Лицензия, Developer ID/notarization и публичный релиз требуют отдельного решения и не входят в текущую разработку. Владелец 2026-10-05 разрешил агенту сделать коммит и пуш текущего checkpoint; основная ветка origin — main, назначение пуша уточняется, поскольку master отсутствует.
