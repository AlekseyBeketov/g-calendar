# Открытые решения и внешняя приёмка

Обновлено: **2026-10-14**. Здесь перечислены только незакрытые продуктовые и внешние вопросы. Исторические Git checkpoint и старые статусы см. в датированных планах и [verification](verification.md).

## Продуктовые решения

- **Точное время Google Tasks.** Public Tasks API предоставляет date-only `due`. Внутренние read/write поля времени наблюдались в Google Calendar Web, однако Tasks Private API недоступен в проверенном OAuth-проекте. Для клиентской реализации нужен доступный и безопасный transport, точная identity и read-back. Локальное время не считается синхронизацией Google. Подробные доказательства и ограничения: [исследование](google-tasks-time-research-2026-10-12.md); активная задача — [OpenSpec 19.2](../openspec/changes/g-calendar-mvp/tasks.md).
- **Лицензия и публичный выпуск.** В репозитории нет выбранной лицензии. Локальные installer/release scripts не публикуют приложение.
- **Security reporting и поддержка пользователей.** Не определены частный канал связи, поддерживаемые версии и сроки ответа. Не создавать `SECURITY.md` с выдуманным контактом или SLA.

## Приёмка и совместимость

- **Developer ID и notarization.** Для подписанного выпуска нужны действующие identity, Team ID и Keychain profile владельца. Credentials не хранятся в репозитории; ad-hoc подпись не подтверждает публичный издательский статус.
- **Чистый Mac.** До выпуска проверить скачанные подписанные assets, первый запуск с сохранённым quarantine и обновление с сохранностью пользовательских данных.
- **VoiceOver.** AX labels и клавиатурные сценарии проверялись; полный ручной голосовой проход ещё не выполнен.
- **Уведомления.** Доставка собственного тестового уведомления в Notification Center подтверждалась; видимый системный баннер требует человеческого наблюдения.
- **Матрица совместимости.** Bundle задаёт macOS 13+ и arm64; локальная проверка проводилась на более новой macOS. Полный прогон целевых версий macOS не выполнен. Поддерживаемый диапазон версий `gws` не закреплён.

Разрешённые тесты собственных синтетических Google-объектов и правила обращения с их exact IDs описаны в [HUMAN_APPROVALS](HUMAN_APPROVALS.md). Не помещать credentials, кэш, drafts и личные screenshots в публичные отчёты.
