# Статус g-calendar

Обновлено: **2026-10-07**. Текущие исходники собираются; Computer Use доступен. Разработка и финальная локальная приёмка завершены по [ExecPlan](plans/2026-10-05-final-product-completion.md) и [OpenSpec](../openspec/changes/g-calendar-mvp/tasks.md).

## Реализовано и проверено

- Утверждён **Pixel Paper** с компактными строками задач и метаданными **Color Atlas**. Сохранены два выбранных референса; отвергнутые варианты удалены. Стек SwiftUI/AppKit сохранён.
- Полные зоны клика в sidebar, независимые выбор календаря и его видимость, компактные сроки/теги задач, сворачиваемые группы, отдельные задачи без срока и future-only Upcoming.
- Нативный поиск и клавиатурная навигация, закреплённые шкала времени и заголовки календаря, достижимое переполнение событий/задач на весь день.
- Общие отступы форм **24/16/8 pt**, соразмерные окна, доступные нижние кнопки и читаемый просмотр событий только для чтения. Проведены кодовый аудит и внешняя проверка основных поверхностей.
- В Computer Use проверены Light/Dark/System, ready/stale/offline/failed/empty, поиск и отсутствие результатов, маленькое окно, формы и настройки. Прежний сбой helper при чтении Settings устранён.
- Журнал неподтверждённых Google-записей защищён межпроцессным lock и проверкой identity; повторная запись при неизвестном результате не выполняется. Busy блокирует создание и изменение объектов.
- Актуальная оптимизированная сборка `run-54154` успешна. Обычный и оптимизированный model suite прошли по **440 assertions**, нативный UI suite — **20 assertions**, installer suite — **26 сценариев**. Финальная компоновка busy и Cmd+N подтверждены в коротком окне; результаты — [verification](verification.md).

Финальная локальная приёмка завершена: сборка, UI, отступы и установка проверены. Публичный подписанный выпуск имеет отдельные внешние условия ниже.

## Производительность

Получен [GUI baseline](GUI_PERFORMANCE.md) с [агрегатами](gui-performance-baseline.json) на синтетических данных. Он измеряет реакцию до update AppKit и задержку планирования RunLoop; это **не pixel latency, FPS или GPU trace**. Небольшие выборки и границы измерения учитываются при выборе бюджетов. Модельные микроизмерения не заменяют GUI-приёмку.

## Установка и распространение

Реализованы [установка из исходников](INSTALLATION.md), локальный DMG/ZIP, установщик закреплённой release-версии, безопасное обновление/rollback и удаление bundle с сохранением данных. Локальные пакеты имеют **ad-hoc** подпись. Подготовлены [Developer ID/notarization scripts](RELEASING.md), но подписанный скачанный релиз, чистый Mac и публичная публикация не проверялись: для них нужны отдельные credentials и решение владельца.

## Внешние решения и история

Полный голосовой проход VoiceOver и человеческое подтверждение видимого notification banner не заявляются выполненными. Ранее два actual-app synthetic Google lifecycle прошли по 11 проверенных шагов с удалением всех собственных объектов; тестовое уведомление доставлено в Notification Center. Точный scope и результаты — [verification](verification.md).

Checkpoint **62f153f** — исторический коммит. В текущем продолжении коммиты, push и GitHub Release не выполнялись. Лицензия, подпись и публичное распространение перечислены в [открытых решениях](PENDING_DECISIONS.md). Личный `download.html`, кэши и credentials не включаются в результат.
