# Статус g-calendar

Обновлено: **2026-10-15**. Это краткий срез текущего состояния; подробные критерии и результаты отдельных этапов сохранены в [OpenSpec](../openspec/changes/g-calendar-mvp/tasks.md), [согласованных дизайнах](plans/) и [журнале проверок](verification.md).

## Реализовано

- Нативный macOS-клиент на SwiftUI/AppKit: календарь в режимах «День», «Неделя» и «Месяц»; списки задач и альтернативное представление колонками.
- Прямой Google REST/OAuth — основной способ подключения: при первом запуске приложение показывает обязательный вход через Google и начинает синхронизацию только после разрешения. `gws` остаётся дополнительным транспортом в настройках. Изменения Google выполняются явно и подтверждаются точным чтением ресурса.
- Рабочее пространство задач: общая лента досок, поиск и сортировки, собственный порядок, перенос задач, настройки досок и локальные метаданные.
- Обновление открытого диапазона календаря в работающем приложении: свежесть проверяется периодически, сетевое чтение ограничено TTL кэша. При активации приложения диапазон также перепроверяется.
- Автоматические уведомления по настроенным Google popup reminders событий. Уведомление содержит название события, локализованные дату и время, место при наличии. macOS берёт значок из bundle; сборка и проверка пакетов требуют `WorkspaceIcon.icns`, а уже доставленный старый баннер не меняется задним числом.
- Установщик из исходников и локальные DMG/ZIP, безопасные обновление и откат. Эти пакеты не являются подписанным публичным релизом.
- Версия 0.2.0 (build 2), SemVer/build-number helper, CHANGELOG и Sparkle 2.10.0. Во втором шаге настройки и в Settings доступен флажок автообновления; отдельно есть ручная проверка. Helper подготовки создаёт DMG/ZIP и EdDSA-подписанный appcast для GitHub Releases. Первый публичный appcast ещё не опубликован.
- Окно добровольной поддержки автора из постоянного footer настроек: CloudTips по умолчанию, Boosty вторым, отдельные QR и логотипы, открытие браузера и копирование ссылки.

## Открытая продуктовая задача

Google Tasks public API предоставляет срок как дату без времени. Синхронизация точного запланированного времени задачи и уведомления по нему остаются незавершёнными: доступ к обнаруженному внутреннему сервису отсутствует в проверенном OAuth-проекте. Подтверждённое состояние и варианты дальнейшей проверки описаны в [исследовании времени Google Tasks](google-tasks-time-research-2026-10-12.md); критерий этой задачи — [OpenSpec 19.2](../openspec/changes/g-calendar-mvp/tasks.md).

## Внешняя приёмка и решения

- Полный ручной проход VoiceOver и повторная человеческая проверка будущего баннера после перезапуска приложения не завершены. Доставка тестового уведомления в Notification Center не доказывает показ баннера.
- Публичный подписанный релиз не готов: нужны решение о лицензии и допустимый для владельца способ подписи/notarization; владелец не оформляет Apple Developer Program.
- Не определены канал security reporting/support и матрица совместимости с версиями `gws` и macOS, кроме проверенной локальной конфигурации. См. [открытые решения](PENDING_DECISIONS.md).

Новые проверки 2026-10-15: 989 invariant assertions, 106 проверок геометрии задач, 26 installer scenarios, подпись настоящего ZIP, отклонение изменённого архива и безопасная распаковка Sparkle. Живой OAuth и видимый баннер требуют ручного подтверждения.

Предыдущая полная UI/installer-приёмка в [verification.md](verification.md) относится к 2026-10-07/08. Изменения после неё проверяются по связанным планам и OpenSpec; старые результаты тестов не являются прогоном всего текущего `main`.
