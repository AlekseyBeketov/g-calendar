# Roadmap

Обновлено: **2026-10-14**. Основной продуктовый объём локального клиента реализован. Этот roadmap показывает текущую границу продукта и реальные следующие направления; подробные открытые решения находятся в [STATUS](STATUS.md), [FUTURE](FUTURE.md) и [PENDING_DECISIONS](PENDING_DECISIONS.md).

## Текущее состояние

- Нативное приложение macOS для Google Calendar и Google Tasks на SwiftUI/AppKit.
- Календарь «День / Неделя / Месяц», видимые события и date-only задачи; задачи доступны единой лентой, списками или колонками.
- `gws` и прямой REST/OAuth — поддерживаемые варианты чтения/записи. Google-мутации требуют явного действия и exact read-back.
- Автоматические уведомления учитывают настройки popup reminders Google Calendar. Открытый календарный диапазон обновляется, пока приложение работает; работа фоновой синхронизации после выхода приложения не обещается.
- Локальные установочные сценарии и release tooling реализованы, но публичный подписанный выпуск не опубликован.
- Добровольная поддержка автора доступна из нижнего footer настроек: CloudTips выбран по умолчанию, Boosty дополнительный; QR, открытие браузера и копирование ссылки.

## Следующие продуктовые направления

1. **Время Google Tasks.** Реализовать доказанный read/write запланированного времени и точные уведомления можно только после нахождения доступного и поддерживаемого канала. Public Tasks API сохраняет due как дату; внутренний сервис недоступен в проверенном OAuth-проекте. Единственный незакрытый OpenSpec-критерий — [19.2](../openspec/changes/g-calendar-mvp/tasks.md).
2. **Полировка и ручная приёмка.** Остались полный VoiceOver-проход, наблюдение видимого notification banner, ручная проверка курсора и прокрутки, измерения производительности и аудит отступов. Детали и границы проверок — в [FUTURE](FUTURE.md).
3. **Транспорт и совместимость.** Сравнить REST и `gws` на живых read-only запросах и зафиксировать поддерживаемый диапазон версий `gws`; синтетический benchmark не заменяет эту проверку. См. [план REST](GOOGLE_REST.md).

## Распространение

Публичный выпуск потребует выбора лицензии, Developer ID и notarization, подписанных versioned assets и теста скачанного приложения на чистом Mac с сохранённым quarantine. Homebrew и Intel-сборка — возможные отдельные решения после такого выпуска. Сейчас заявлена arm64-сборка с deployment target macOS 13+.

## Не планируется

- Hosted backend, push relay, платная служба синхронизации или telemetry по умолчанию.
- Скрытые Google-записи, неявная offline write queue, выдуманное время для date-only Tasks due или уведомления без разрешения macOS.
